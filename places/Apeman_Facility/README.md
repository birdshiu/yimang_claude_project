**Apeman Facility** is a teal-colored zone that, presumably, was supposed to be administrated by Yi, as signified by his statues (although they have Kuafu's seal mark on the plate below).

Central Core Chip is the map data chip unlocking details on this zone. It can be obtained from the Shanhai 9000 in the Cortex Center that can only be found in later stage of the game , implying that Apeman facility is part of the Central core zone.
